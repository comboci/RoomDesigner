- Baseline: main@5d7f5734f90c48faecbe1dfe188d7257d561f8cb (V410-R). Focused static remediation of RD-A03/A05 and damaged local recovery; no sequential/full repository coverage claimed.
- RD411-A05-GENERATED-ARTWORK (P1): prior Revision pinning only captured explicit SVG IDs/inline content, not the effective LightingModel/catalog/fallback artwork. New snapshots also store a detached versioned historicalArtwork manifest (deduplicated sanitized SVG strings and device-ID/face/detail indices). Capture the current effective face and requested product detail view before changing inline provenance. No live renderer freeze; original semantic geometry and V410 explicit SVG pinning retained. Image assets and DXF geometry retain existing mechanisms. Existing 250,000 chars per asset / 3.2-million raw SVG chars per snapshot / 12-million serialized document chars budgets remain; additional visual capture consumes that budget. Missing required generated face/detail or unsafe/oversized SVG stops a new Revision before publication. Import validates historical artwork indices and SVG safety without normalizing stored historical inline snapshots. A read-only historical SVG preview and selected SVG/bundle export are available from Revision history. Editable restore explicitly warns that it uses the current renderer; old revisions cannot reconstruct artwork already changed. Not a pixel-identical full canvas recording or a frozen catalog for all future editable modes.
- RD411-A03-BLOCKED-RAW-ACCESS (P1): blocked writer/startup, migration errors and divergent recovery gates previously lacked independent single-record raw access. Add controls that do not depend on initialized editor/notification state or writer lock. List rd_ LocalStorage keys and string keys in the existing dedicated IndexedDB backups store without loading values; open existing database only, abort an attempted creation, use readonly transactions, read one selected record and close the temporary connection. Export original local string or JSON-compatible IDB value in a versioned envelope; refuse lossy JSON conversion of unexpected structured-clone values. No writes/deletion/reconciliation in this UI, and anchor download is only a request, not confirmation of physical file retention. Partial source reads reported. A concurrent writer may change a selected record between listing and read; the exported value is the one read, not a coherent cross-store snapshot.
- RD411-A01-A03-DAMAGED-DATA (P1): invalid critical managed records cannot silently be overwritten with fallback defaults; startup blocks editing when detected and offers raw export. Invalid rd_last external backup approval now binds exact durable managed related bytes, mirror/metadata and current editor; recheck after export, confirmation and immediately before replacement. If mirror read fails, partial export remains possible but replacement is not authorized; stale approval is cleared. Explicit recovery requires primary write success before scheduling mirror replacement; normal Autosave behavior is not changed. Existing workspace restore transaction / rollback / receipt protections remain separate.
